# Telegram-бот «Острошицкий городок — Восток»

Бот отвечает на сообщения о ближайших трёх рейсах №451 и №2198. Расписание внесено по присланным фотографиям; №1554 и №1464/1564 в проект не включены. №451 добавлен в обоих направлениях: со ст. м. «Восток» до Острошицкого городка и из Острошицкого городка в Минск. №2198 также добавлен в обоих направлениях: из Минска до Острошицкого через Чуденичи и из Острошицкого городка-2 в Минск / к ст. м. «Восток».

## Запуск на Windows

1. Установи Python 3.11 или новее.
2. В Telegram открой `@BotFather`, выполни `/newbot` и скопируй токен.
3. Открой PowerShell в этой папке и выполни:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
py bot.py
```

В `.env` замени значение `BOT_TOKEN` на токен от BotFather. Пока окно PowerShell открыто, бот работает.

## Примеры сообщений

- `Когда ближайшая маршрутка до Востока`
- `Через 15 минут буду на Востоке, когда ближайшая до Острошицкого?`
- `Я сейчас на Востоке, когда ближайший автобус?`
- `Я в Острошицком, когда ближайшая маршрутка в Минск?`
- `Ближайший 451 до Острошицкого зимой`
- `/лето`, `/зима`, `/авто` — ручной или автоматический выбор сезона для №451.
- `2198 до Востока`

По умолчанию бот считает апрель–октябрь летом, ноябрь–март зимой. Для проверки конкретного сезона напиши в запросе `летом` или `зимой`.

## Что можно менять

Все часы находятся в `schedule_data.json`. Если перевозчик изменит расписание, редактировать нужно только этот файл — код бота менять не требуется.

Важная точность: расписание №451 на новом фото — со ст. м. «Восток» в сторону Острошицкого; надпись «АС Славінскага — АС Лагойск» обозначает маршрут. Отдельного расписания №451 из Острошицкого обратно в Минск на фото нет, поэтому бот не придумывает такие рейсы и показывает там только №2198.
