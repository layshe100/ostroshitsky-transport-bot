# Telegram-бот «Острошицкий городок-2 — Восток»

Бот отвечает на сообщения о ближайших трёх рейсах №451, №2198, №1464 и №1554. Все направления приведены к остановке «Острошицкий городок-2»: со ст. м. «Восток» туда и обратно к ст. м. «Восток».

## Запуск на Windows

1. Установи Python 3.11 или новее.
2. В Telegram открой `@BotFather`, выполни `/newbot` и скопируй токен.
3. Открой PowerShell в этой папке и выполни:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
py bot.py
```

В `.env` замени значение `BOT_TOKEN` на токен от BotFather. Пока окно PowerShell открыто, бот работает.

## Примеры сообщений

- `Когда ближайшая маршрутка до Востока`
- `Через 15 минут буду на Востоке, когда ближайшая до Острошицкого?`
- `Я сейчас на Востоке, когда ближайший автобус?`
- `Я в Острошицком городке-2, когда ближайшая маршрутка в Минск?`
- `Домой`
- `В город`, `на Восток`, `до метро`, `из Минска`, `из Острошицкого городка-2`
- `туда` или `обратно` после выбора направления
- `Ближайший 451 до Острошицкого городка-2 зимой`
- Кнопка `Выбрать время` показывает варианты `Через 30 минут`, `Через 1 час`, `Утром`, `Днём`, `Вечером` и `Ввести время`.
- После выбора направления можно написать время вручную, например `18:00`.
- `/summer`, `/winter`, `/auto` — ручной или автоматический выбор сезона для №451.
- `/start`, `/next`, `/time`, `/help`, `/feedback` — основные команды бота.
- `2198 до Востока`

По умолчанию бот считает апрель–октябрь летом, ноябрь–март зимой. Для проверки конкретного сезона напиши в запросе `летом` или `зимой`.

Ответы являются расчётом по сохранённому расписанию, а не отслеживанием транспорта в реальном времени. В каждом результате указано, что фактическое время прибытия может отличаться. Расписание обновлено 20.08.2026 по фотографиям остановочных расписаний и онлайн-страницам №1464 и №1554 на tuda-suda.by. Праздничные даты 2026 года считаются выходными; переносы рабочих дней специально не учитываются.

## Что можно менять

Все часы находятся в `schedule_data.json`. Если перевозчик изменит расписание, редактировать нужно только этот файл — код бота менять не требуется.

Важная точность: расписание №451 внесено в обоих направлениях по присланным фотографиям. Надпись «АС Славінскага — АС Лагойск» на одном фото обозначает маршрут, а не отдельную остановку «Славинского».
